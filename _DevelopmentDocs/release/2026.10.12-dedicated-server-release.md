# Dedicated Server exclusion release

Published release: `2026.10.12-1`. Work date: `2026-10-12`. Baseline: published `2026.10.7-6` / main `9b8ebaf`.

## Change

- Fix [issue #42](https://github.com/romanilyin/sgg-perfmeter/issues/42), reported by [AndrzejKebab](https://github.com/AndrzejKebab).
- All six player runtime assemblies, both PlayMode assembly definitions and three runtime sample assemblies use `!UNITY_SERVER || UNITY_EDITOR`. Editor-only assemblies remain available, including when the server target is selected.
- Exclude legacy Linux headless simulation using the valid asmdef platform name `CloudRendering`. Unity `6000.6.5f1` does not report `LinuxHeadlessSimulation` or `macOSStandaloneServer` as asmdef names; the server define covers desktop server targets without depending on that list.
- Add assembly definitions for BootstrapAndSettings and RuntimeWorkflows so imported sample scripts cannot fall into Assembly-CSharp and reference the excluded runtime.
- Document guards for consumer code and distinguish Dedicated Server builds from ordinary clients launched with `-batchmode -nographics`.
