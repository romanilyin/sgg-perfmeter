# 2026.8.7-2 Setup FTUE Release

Status: published.

## Scope

- Version/tag: `2026.8.7-2`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-08`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Added a separate first-time setup tab with live required checks, optional dependency actions, explicit skip choices, and automatic hide/reappearance as setup readiness changes.
- Added independently persisted Editor warning-log and structured-log controls while preserving schema `1` compatibility and enabled-by-default legacy behavior.
- Added package-version visibility to the Setup window title/header and localized the new static FTUE surface in every supported language.

## Release Notes

- Guide first-time users through import/runtime/render compatibility, Frame Timing Stats, package discovery, project JSON settings, diagnostics, and logging without removing the existing Setup, Presets, Runtime, or Debug tabs.
- Install optional Unity packages through UPM, open official RenderDoc/PIX download pages, or explicitly skip each optional step. Unity's shared external-profiler attachment signal is not used to claim that both RenderDoc and PIX are available.
- Persist structured-log enablement independently from Editor warning logs and retain safe defaults when older schema `1` JSON omits the new field.
- Show `2026.8.7-2` in the Setup window and assembly/package metadata.
