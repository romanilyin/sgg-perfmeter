# 2026.8.19-1 RenderDoc GPU Annotations Release

Status: release candidate.

## Scope

- Version/tag: `2026.8.19-1`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-19`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Native support row: Windows x64 Unity Editor with RenderDoc v1.46 on Direct3D 12.
- Optional artifact: `sgg-perfmeter-renderdoc-bridge-2026.8.19-1-windows-x64.zip` plus its `.sha256` file, distributed separately from the binary-free UPM package.

## Release Notes

- Added a RenderDoc-neutral public API for bounded typed GPU command annotations, ambient owner/generation context, and direct URP Render Graph command-buffer scopes.
- Added schema v1 machine keys, bounded typed values, explicit no-op statuses, non-nested scopes, and deterministic clearing after the annotated draw or dispatch.
- Extended the optional Windows x64 Editor bridge with an additive annotation ABI, generation-safe fixed packet pool, Unity native-plugin lifecycle, and initial Direct3D 12 command annotation transport.
- Preserved compatibility with the published capture-only bridge: capture remains available, while annotation calls report `BridgeTooOld` until the package-pinned `2026.8.19-1` artifact is installed.

## Boundaries

- Annotation transport is Windows x64 Unity Editor/Direct3D 12 only in this release and requires an already-loaded RenderDoc App API `1.7` instance plus an active capture.
- D3D11, Vulkan, Player, IL2CPP, Linux, mobile, Metal, nested scopes, and resource/object annotations require separate validation gates.
- The UPM package remains binary-free; neither the package nor bridge ships, loads, injects, or installs RenderDoc.
- Repository-facing npm and Git UPM install examples remain on published `2026.8.15-1` until GitHub/npm publication, provenance, and clean-consumer verification complete. The immutable release tag retains those prepublication package README pins by design.
