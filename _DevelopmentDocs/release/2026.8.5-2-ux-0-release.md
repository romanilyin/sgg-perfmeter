# 2026.8.5-2 UX_0 Release

Status: release candidate prepared; not published.

## Scope

- Version/tag: `2026.8.5-2`.
- Package: `com.sungeargames.perfmeter`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Built-in Render Pipeline remains unsupported.
- Validation in this implementation pass targets Unity `6000.5.6f1`; the full version/platform matrix is a separate final release gate.

## Release Notes

- Added `PerformanceMeter.StructuredLogsEnabled` and `PerformanceMeter.SetStructuredLogsEnabled(bool)` as an independent structured alert-log control.
- Added stable numeric prefix/value/unit cells, monospace numeric rendering, bounded `FpsOnly` fallback and wrapping cards/budget bars.
- Added a dedicated owned UI Toolkit host with `UIDocument` on Unity 6000.4 and `PanelRenderer` on Unity 6000.5+.
- Preserved foreign UI Toolkit settings and children and limited rebuild removal to the PerfMeter-owned container.
- Added PlayMode coverage for responsive geometry, max-font widget bounds, numeric width stability, host ownership and repeated lifecycle/rebuild operations.
- Updated all supported localized user documentation for the new API and overlay behavior.
