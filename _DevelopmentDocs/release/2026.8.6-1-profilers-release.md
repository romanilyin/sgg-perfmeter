# 2026.8.6-1 Profiler Observability Release

Status: published.

## Scope

- Version/tag: `2026.8.6-1`.
- Package: `com.sungeargames.perfmeter`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Built-in Render Pipeline remains unsupported.
- HDRP overdraw and heatmap remain unsupported; core diagnostics and self-observability remain available.

## Release Notes

- Added a startup-cached dynamic Profiler metric catalog with exact/alias resolution provenance and explicit sample availability.
- Added dependency-free Unity Profiler markers and end-of-frame counters for collection, providers, snapshots, bottleneck classification, captures, exports, timing availability, and runtime state.
- Added fixed 120-frame CPU/allocation self-overhead windows and per-invocation budgets for collector, custom providers, CPU-core sampling, overlay, URP, and HDRP callbacks.
- Published additive self-overhead snapshots through the runtime API, status, and MCP without subtracting from existing CPU/GPU metrics.
- Kept GPU self-attribution explicitly `Unavailable` and inactive render integrations explicitly `Unsupported`.
- Updated all supported localized API, MCP, and workflow documentation.
