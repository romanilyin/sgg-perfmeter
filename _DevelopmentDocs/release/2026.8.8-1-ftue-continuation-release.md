# 2026.8.8-1 FTUE Continuation Release

Status: published.

## Scope

- Version/tag: `2026.8.8-1`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-08`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Added guided post-install and external-tool continuation actions for Memory Profiler, Profile Analyzer, Adaptive Performance, RenderDoc, and GraphicsStateCollection.
- Added a complete self-contained generated bootstrap through `PerformanceMeter.TryApplySettingsJson(...)`, including logging, alerts, session defaults, overdraw, collection, and visual settings.
- Made valid explicit settings deterministic over Resources auto-start while keeping invalid JSON non-mutating.
- Added localized workflow guidance and copyable runtime snippets without automatically starting sessions, snapshots, traces, prewarm, or GPU captures.

## Release Notes

- Installed optional package rows now explain and expose their next usable action instead of ending at `Available`.
- RenderDoc guidance covers installation, Unity's `Load RenderDoc` flow, launch-through-RenderDoc fallback, attachment checks, capture requests, and the external-profiler identity/artifact limitations.
- Memory Profiler provides one-shot and runtime-trigger snippets plus snapshot-folder reveal; Profile Analyzer documents the required Unity Profiler recording order.
- GraphicsStateCollection provides trace/prewarm snippets, Runtime status, artifact reveal, and the required session-to-artifact-to-prewarm sequence.
- Initialization Code embeds the normalized Project Settings snapshot, including Editor warning logs and structured logs, and remains separate from explicit capture/profiling operations.
