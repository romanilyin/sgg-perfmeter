# 2026.8.13-1 RenderDoc Analyzer Release

Status: release candidate.

## Scope

- Version/tag: `2026.8.13-1`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-13`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Added Editor-side experimental infrastructure for the versioned RenderDoc analyzer protocol, out-of-process replay analyzer, and deterministic counter selection planner; no public UI, API, or MCP entry point is exposed yet.
- Recorded the accepted fail-closed native PIX timing boundary without adding a native PIX backend or artifact.

## Release Notes

- Analyzer request/result/error JSON Schema v1 preserves exact unsigned values, unknown future units/types, explicit availability, action hierarchy, requested/fetched state, replay-pass provenance, and authenticated capture/hash evidence.
- The package-owned experimental Python sidecar runs through a separately configured user-owned `qrenderdoc`, uses a marker-owned isolated profile/workspace, verifies capture SHA-256 before and after replay, and bounds actions, counter results, response bytes, logs, timeout, cancellation, and process-tree cleanup.
- Counter planning supports canonical explicit IDs and `core`, AMD, Intel, NVIDIA, Vulkan-extended, and ARM semantic packs with deterministic vendor/API applicability and stable 16-counter passes.
- Generic batch failures may retry each counter independently; vendor/private counter passes are not retried. Partial/empty results, fatal replay status, invalid result identity, unsupported counters, and per-result conversion failures remain explicit rather than becoming zero or substituted data.

## Boundaries

- RenderDoc remains separately installed, configured, and owned by the user. The package ships no RenderDoc binary and loads no replay library into Unity.
- The analyzer is Editor-side experimental infrastructure, not a runtime hot-path dependency, and has no public UI, API, or MCP invocation path in this release.
- Dynamic vendor-pack completeness in schema v1 relies on the producer-authenticated `counter_catalog_complete` declaration because v1 has no independent available-counter inventory.
- Vulkan analyzer replay remains unverified because the pinned capture fails during `open_capture` before action/counter planning.
- Native PIX circular pre-alert timing capture remains unavailable until a documented bounded Windows API exists. Generic PIX remains GPU-frame-only and non-authoritative.
- The optional Windows x64 RenderDoc app-API bridge remains the separately published `2026.8.11-1` artifact; no native artifact is published for this release.
- Repository-facing public npm and Git UPM install pins remain on `2026.8.12-1` until GitHub/npm publication, signatures, provenance, and clean-consumer installs for `2026.8.13-1` are verified.
