# 2026.8.9-1 Core Hardening Release

Status: published.

## Scope

- Version/tag: `2026.8.9-1`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-09`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Core hardening slice: `PM-CORE-001..003`, core `PM-COMP-002`, `PM-CI-002`, and generic `PM-EXT-001/002`.
- Added non-blocking single-flight capture-bundle export request/status/cancel APIs and MCP commands while retaining the blocking compatibility surface.
- Added additive typed missing-sample/capture-boundary timelines, allocation-free warmed custom metric collection, and backward-compatible timeline/schema readers.
- Added a generic external-artifact authority/hash/privacy envelope, process-local profiler conflict leases, and an opt-in hosted PlayMode CI matrix.

## Release Notes

- Capture-bundle export snapshots Unity-owned state before asynchronous serialization, artifact copy/hash, staging, and commit work, with cancel/status/progress and a blocking compatibility wrapper.
- Warmed custom metric collection reuses core-owned storage without taking the registry lock or creating a compact array on the collection path.
- Timeline and schema changes remain additive: missing samples and capture boundaries are typed, invalid timing is not written as numeric zero, and legacy/unknown timeline data remains readable.
- External artifacts carry generic authority, association, host, hash, finalization, GPU-capture, privacy, and project-local policy metadata without claiming authority from extension or hash alone.
- Capture, memory, graphics trace/prewarm, and alert workflows share process-local profiling conflict leases without replacing the lifecycle of a concrete external tool backend.
- The hosted PlayMode workflow is opt-in and remains gated by GameCI credentials.
