- Implements roadmap item `PM-UI-009` for the existing smoothed CPU and GPU timing graphs.

## Release Notes

- Per-frame CPU/GPU timing samples accumulate a valid raw maximum between throttled history-graph samples.
- Semantic-red peak segments render behind the existing graph line/fill and only the excess above the foreground shape remains visible.
- Horizontal compression selects the maximum valid raw peak in each rendered pixel bucket, so a one-frame spike is not averaged away.
- Raw peaks are projected and clipped into the already selected vertical range. They do not participate in scale calculation and cannot change scale labels, budget lines, or foreground coordinates.
- Invalid, unavailable, non-finite, duplicate, and stale timing samples do not create peak evidence.

## Boundaries

- This release uses the explicitly requested one-time Unity `6000.4` through `6000.7` validation matrix. Subsequent PerfMeter releases return to one primary Unity validation version unless a broader matrix is explicitly requested.
- The raw peak backdrop is a default visual refinement. It adds no public API, preset/schema field, setting, or user toggle.
- Peak evidence changes only graph rendering. It does not change raw timing metrics, alerts, spike counters, session/capture data, smoothing/sampling semantics, or the separate RAW strip.
- The optional Windows x64 RenderDoc bridge remains the separately published `2026.8.11-1` artifact; no native artifact is published for this release.
