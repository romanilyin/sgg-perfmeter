# 2026.8.13-2 Overlay Corrections Release

Status: published.

## Scope

- Version/tag: `2026.8.13-2`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-13`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Fixes target-FPS budget persistence and the RAW strip severity palette without changing the RAW scale.
- Expands built-in visual preset width caps, simplifies the zero-code Default CPU-core composition, and persists `Presets > Save` as the active project/build preset.

## Release Notes

- The RAW frame-time strip retains its target-FPS budget through theme/font visual rebuilds and now uses dark green, blue, yellow, and red severity bands, with the former orange range merged into yellow.
- All built-in visual presets use the bounded `780 px` cap. Responsive wrapping remains active on narrow viewports, while custom preset widths are not migrated.
- CPU-core bars are disabled only in the zero-code Default configuration; Full Diagnostics and explicit module selection remain available.
- `Presets > Save` saves the descriptor, activates it in project Resources settings, and bakes all valid project descriptors for subsequent Play Mode sessions and builds without persisting unrelated unsaved controls or dropping unknown same-schema top-level fields.
- Recommended setup preserves valid settings and refuses to overwrite invalid or newer-schema JSON. Android smoke startup applies Resources settings and respects explicitly stopped configurations.
