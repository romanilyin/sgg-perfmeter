## Included behavior

- Standalone menu **SGG > Perfmeter > Frame Debugger Export**, backed by public `PerfMeterFrameDebuggerExport` service and a separate Editor-only assembly; Gateway is not required.
- Export an already enabled local capture to separate versioned JSON, compact CSV, optional long-form shader properties and a SHA-256 manifest in `Temp/PerfMeter/FrameDebuggerExports/<export-id>/`.
- Exact event success/index checks, count/list/hash/target/selection consistency, bounded timeouts, progress, cancellation, explicit partial/unavailable results and conditional ownership-safe selection restoration.
- Atomic publication, bounded data/output/retention and marker-owned cleanup. Runtime collection is not started; an existing session records additive `EditorDiagnostic` gaps during traversal.
- Reader schema/fixture and English/Russian workflow guides with localized discovery links.
