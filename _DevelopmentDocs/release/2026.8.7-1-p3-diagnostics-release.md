# 2026.8.7-1 Combined P3/P3.5 Diagnostics Release

Status: published.

## Scope

- Version/tag: `2026.8.7-1`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-07`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- P3/P3.5 scopes: `PM-MEM-001` optional memory snapshots, `PM-GFX-001` shader/PSO diagnostics and `GraphicsStateCollection` trace/prewarm, `PM-REN-001` integration-neutral render context, `PM-GRD-001` truthful GRD/BRG telemetry, `PM-CI-001` session IDs/Profiler correlation/Profile Analyzer opener/performance CI, `PM-SESSION-001` read-only Session Analysis UI, and `PM-SETUP-001` complete Setup UX.
- Built-in Render Pipeline remains unsupported.
- HDRP overdraw and heatmap remain unsupported; core diagnostics remain available.

## Release Notes

- Added optional `PM-MEM-001` Memory Profiler snapshot triggers for manual, threshold, and leak workflows with cooldown, free-space guards, capture flags, and bundle manifest metadata.
- Added `PM-GFX-001` shader/PSO and graphics-pipeline diagnostics plus optional `GraphicsStateCollection` trace/prewarm lifecycle handling with capability provenance, session correlation, cancellation, and owned cleanup.
- Added the integration-neutral `PM-REN-001` render context snapshot for camera, SRP/pass, freshness, GRD, and VRS context while keeping URP/HDRP public-API boundaries explicit.
- Added truthful `PM-GRD-001` GRD/Forward+/compute support, global activity, and aggregate BRG effectiveness telemetry with provenance and degraded reasons rather than per-renderer claims.
- Added `PM-CI-001` session IDs, Profiler correlation markers, an optional Profile Analyzer opener without a hard dependency, and versioned performance baseline/CI artifact surfaces.
- Added the read-only `PM-SESSION-001` virtualized UI Toolkit Session Analysis window with retained-sample timeline, worst-frame inspection, derived budget violations, and whole-run/current-scene scopes.
- Completed `PM-SETUP-001` Setup UX presentation for persisted P2/P3 settings, optional integrations, analysis entry points, and read-only compatibility/schema/diagnostic states with runtime-only boundaries.
