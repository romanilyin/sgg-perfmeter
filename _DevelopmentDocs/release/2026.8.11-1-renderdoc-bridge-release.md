# 2026.8.11-1 RenderDoc Bridge Release

Status: published.

## Scope

- Version/tag: `2026.8.11-1`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-11`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Native support row: Windows x64 Unity Editor with RenderDoc on Direct3D 11, Direct3D 12, or Vulkan.
- Optional artifact: `sgg-perfmeter-renderdoc-bridge-2026.8.11-1-windows-x64.zip` plus its `.sha256` file, distributed separately from the binary-free UPM package.

## Release Notes

- Added verified FTUE download, local-file installation, update, cancel, status, and managed removal for the separately published Windows x64 Editor bridge. The installer accepts only the exact package-pinned size, SHA-256, and native AMD64 PE contract and configures every player target off.
- RenderDoc remains user-installed and user-owned. The bridge resolves only an already-loaded `renderdoc.dll`; it never installs, loads, injects, launches, or bundles RenderDoc or replay binaries.
- Added explicit `GenericUnity`, `NativePreferred`, and `NativeRequired` request modes. The generic Unity path remains the compatibility default and cannot authenticate attached-tool or artifact identity.
- The native path carries generation-bound lifecycle and authenticated provenance into MetadataOnly, Copy, or Embed storage. MetadataOnly defaults to `DoNotShare`; Copy and Embed require explicit review before sharing and use independent limits, retention, ownership, cleanup, and hash verification.
