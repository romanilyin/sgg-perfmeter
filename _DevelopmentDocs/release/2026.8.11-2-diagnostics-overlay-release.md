Status: published.

## Scope

- Version/tag: `2026.8.11-2`.
- Package: `com.sungeargames.perfmeter`.
- Release work date: `2026-08-11`.
- Runtime target: Unity `6000.4+` with URP `17.4+` Render Graph or HDRP `17.4+` Custom Pass integration.
- Included iterations: `PM-OBS-004`, `PM-PLAT-002`, `PM-API-001`, `PM-UI-003`, `PM-UI-004`, `PM-UI-005`, and `PM-OBS-005`.

## Release Notes

- Added stable hysteresis-based bottleneck diagnostics, typed evidence and mutation results, bounded platform-telemetry freshness/cadence, and raw-warning preservation without changing raw frame metrics.
- Added the per-collected-frame hitch strip, up to four independently scaled custom metric graph channels, bounded widget/layout descriptors, responsive graph fallbacks, and public semantic theme manifests.
- Added exact session/capture-bound URP self-overhead provenance with package/window schema identity, epoch/frame/callback bounds, pipeline/quality/renderer and feature installed/enabled/enqueued evidence, typed inactive reasons, and stale-window rejection.
- URP self-overhead remains limited to package-owned CPU-side `RecordRenderGraph()` registration and current-thread allocation. GPU attribution is `Unavailable`; whole-frame CPU/GPU/hitch/GC remains context only.
